# PublicFindCompaniesFilters

Search facets. Provide at least one company-level facet: company, industry, location, or keywords. A company named in company finds companies like it, near its size; say what it sells in industry when you know. A role or title cannot select companies.

## Example Usage

```typescript
import { PublicFindCompaniesFilters } from "bereach/models/operations";

let value: PublicFindCompaniesFilters = {};
```
