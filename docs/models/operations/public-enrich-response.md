# PublicEnrichResponse

Batch result (or a stillRunning partial for a batch that outlived this call's wait)

## Example Usage

```typescript
import { PublicEnrichResponse } from "bereach/models/operations";

let value: PublicEnrichResponse = {
  source: "public",
  batchId: "<id>",
  total: 799113,
  visited: 434378,
  failed: 516928,
  skipped: 838660,
  creditsUsed: 112631,
  status: "failed",
};
```
