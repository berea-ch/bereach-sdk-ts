# PublicFindCompaniesCompanyUnion

Named employer facet: the organisation someone works for, by its own name. One value or a list of alternatives. A word describing the KIND, SIZE or MARKET of a company is not an employer name and belongs in industry.


## Supported Types

### `string`

```typescript
const value: string = "<value>";
```

### `string[]`

```typescript
const value: string[] = [
  "<value 1>",
  "<value 2>",
];
```
