# PublicFindPeopleCompany

Named employer facet: the organisation someone works for, by its own name. A word describing the KIND or MARKET of a company is not an employer name and belongs in industry; nor is its size. Write it the way the organisation spells its own name, correcting an obvious misspelling of one you know.


## Supported Types

### `string`

```typescript
const value: string = "<value>";
```

### `string[]`

```typescript
const value: string[] = [
  "<value 1>",
  "<value 2>",
];
```
