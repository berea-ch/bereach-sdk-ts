# Engagement

Limits for likes and reactions.

## Example Usage

```typescript
import { Engagement } from "bereach/models/operations";

let value: Engagement = {
  uncapped: true,
  daily: {
    current: 760752,
    limit: 305866,
    remaining: 497302,
  },
  weekly: null,
  minIntervalSeconds: 790829,
  nextResetDaily: "<value>",
  nextResetWeekly: "<value>",
};
```
