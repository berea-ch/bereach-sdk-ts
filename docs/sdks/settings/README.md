# Settings

## Overview

Endpoints for DM polling and connection polling configuration

### Available Operations

* [getDmPollingSettings](#getdmpollingsettings) - Get DM polling settings
* [patchDmPollingSettings](#patchdmpollingsettings) - Update DM polling settings

## getDmPollingSettings
