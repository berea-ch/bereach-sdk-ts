# VisitProfileDetail

"preview" (default): a quick look; it can miss the current title and older posts. "full": every detail we have. Choose full for one person when the job title, how long they have held it, or the whole dated career matters.

## Example Usage

```typescript
import { VisitProfileDetail } from "bereach/models/operations";

let value: VisitProfileDetail = "full";
```

## Values

```typescript
"preview" | "full"
```
