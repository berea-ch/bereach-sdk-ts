# PublicFindPeopleSave

keep (the default) when the people are the list being built, skip only when this search is certainly a step toward one person's posts or audience or a check of who somebody is, ask when unsure; narrow first rather than keep then remove; report what was actually written.

## Example Usage

```typescript
import { PublicFindPeopleSave } from "bereach/models/operations";

let value: PublicFindPeopleSave = "keep";
```

## Values

```typescript
"keep" | "skip" | "ask"
```
