# CollectPostsDetail

"preview": a quick look; it can miss older posts and every count but likes. "full" (default): every detail we have. Keep full for every recent post with every count, page after page.

## Example Usage

```typescript
import { CollectPostsDetail } from "bereach/models/operations";

let value: CollectPostsDetail = "full";
```

## Values

```typescript
"preview" | "full"
```
