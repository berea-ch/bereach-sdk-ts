# ConnectProfileBlocked

Set when the account itself cannot send right now. Nothing goes out until this clears, and resumesAt is null when clearing it needs a person.

## Example Usage

```typescript
import { ConnectProfileBlocked } from "bereach/models/operations";

let value: ConnectProfileBlocked = {
  kind: "<value>",
  clearsItself: true,
  message: "<value>",
  resumesAt: null,
  fixUrl: "https://hurtful-follower.name/",
};
```
