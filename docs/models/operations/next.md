# Next

Who goes next overall, named only when exactly one account is live, which includes an account waiting for its sending hours. With several live at once there is no single next person; read the per-account rows instead.

## Example Usage

```typescript
import { Next } from "bereach/models/operations";

let value: Next = {
  contactId: "<id>",
  name: "<value>",
  avatarUrl: "https://tinted-shadowbox.com",
  headline: "<value>",
  linkedinUrl: null,
  lastActivityAt: "<value>",
  thinProfile: false,
  why: {
    status: "waiting",
    detail: "<value>",
    clearsItself: true,
    fixUrl: "https://heavy-eggplant.net/",
  },
  position: 943721,
  sendsAt: "<value>",
  accountLabel: "<value>",
};
```
