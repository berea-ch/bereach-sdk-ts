# PublicFindPeopleSeniority

Seniority words. Used as the title only when title is empty, so with a title put the seniority inside it.


## Supported Types

### `string`

```typescript
const value: string = "<value>";
```

### `string[]`

```typescript
const value: string[] = [
  "<value 1>",
  "<value 2>",
];
```
