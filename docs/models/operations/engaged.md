# Engaged

Filters the saved list by default to people outreach has reached: invited, drafted to, messaged, replied, or marked do-not-contact; pass false for every saved row including people only found, though the flag is ignored whenever campaignId, linkedinUrl or name already names what to return.


## Supported Types

### `operations.EngagedEnum`

```typescript
const value: operations.EngagedEnum = "false";
```

### `boolean`

```typescript
const value: boolean = true;
```
