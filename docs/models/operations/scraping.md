# Scraping

Limits for data collection: search, collecting posts/likes/comments, listing chats

## Example Usage

```typescript
import { Scraping } from "bereach/models/operations";

let value: Scraping = {
  uncapped: false,
  daily: {
    current: 137081,
    limit: 85944,
    remaining: 814423,
  },
  weekly: {
    current: 285349,
    limit: 899452,
    remaining: 708085,
  },
  minIntervalSeconds: 216438,
  nextResetDaily: "<value>",
  nextResetWeekly: null,
};
```
